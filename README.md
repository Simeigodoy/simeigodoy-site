# simeigodoy-site

Página pessoal de Simei Godoy: marca pessoal, investimentos e empresas (Na Via).

- Site estático: `index.html` + `img/`. Sem build.
- Hospedagem: Cloudflare Pages, conectado a este repositório (branch `main`, sem comando de build, pasta de saída `/`).
- Domínio: registrado no registro.br, DNS na Cloudflare.

## Pendências
- Citar a AssetBank pelo nome só depois da aprovação do compliance deles (hoje a página diz "uma instituição financeira").
- Opcional: parágrafo com a história do Simei e e-mail de contato.
